## 关于项目

这是一个我的个人静态主页，使用原生 HTML, CSS, 和 JavaScript 构建。

这个项目旨在展示我的个人项目列表，并作为一个实践前端技术和展示个人风格的平台。项目列表通过 GitHub Actions 自动从我的 GitHub 账户同步，无需手动更新。背景的粒子效果使用了 `particles.js` 库，并实现了可交互的动态效果。

---
## 主要功能

* 🎨 **双主题切换**：支持浅色和深色模式，并能记住用户的偏好。
* 🚀 **动态项目列表**：通过 GitHub Actions 自动获取并展示我的公开项目。
* ✨ **互动背景**：基于 `particles.js` 实现的、可与鼠标交互的动态气泡背景。
* 📱 **响应式设计**：适配不同尺寸的设备。
