# 如何用纯静态文件搭建这个博客
*发布于 2026年1月16日*

为个人主页添加一个博客是分享知识和记录成长的好方法。但很多时候，我们不需要一个像 WordPress 或 Ghost 那样复杂的动态博客系统。对于一个开发者来说，一个纯静态、用 HTML 和 CSS 构建的博客不仅维护简单、加载飞快，而且完全免费（托管在 GitHub Pages 上）。

## 第一步：规划文件结构
我们的目标是简洁。所以我们只需要几个核心文件：
- `index.html` - 你的主页。
- `blog.html` - 新的博客文章列表页。
- `post1.html`, `post2.html`... - 每一篇文章都是一个独立的HTML文件。
- `style.css` - 主样式表。
- `blog.css` - 博客页面的专属样式。

## 第二步：创建文章列表页 (blog.html)
这个页面的作用是作为博客的入口，展示所有文章。每个条目包含标题、日期、摘要和一个“阅读全文”的链接。
```html
<div class="post-entry">
    <h3>文章标题</h3>
    <p class="post-meta">发布日期</p>
    <p>文章摘要...</p>
    <a href="post1.html" class="button">阅读全文</a>
</div>
```

## 第三步：创建文章内容页
这是最简单的部分。你只需要从 `blog.html` 复制基础结构，然后把主要内容区域换成你的文章。为了格式美观，我们需要为代码块 `<pre><code>` 和其他元素添加一些样式。

这就是全部了！通过这个简单的方法，你就有了一个可以随时扩展的静态博客。要发布新文章，只需要复制一份文章模板，修改内容，然后在 `blog.html` 里添加一个新的链接条目即可。
