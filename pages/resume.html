🚀 在线体验 Demo ↗ 📦 GitHub 源码 ↗
▸ 查看架构攻坚与工程细节 (展开 6 项核心设计)
  • 结构化契约与自我修复：基于 pydantic 定义 route schema 作为唯一契约；结合 Agent 反思重试机制，在模型输出校验失败时携带精准错误信息回灌纠错，构建闭环自愈环路。
  • 高可靠六级坐标降级链路与熔断：按可信度确立六级降级（用户记忆真值 → 高德 POI 检索 → 模型知识库 → 联网搜索兜底 → 城市中心表 → 报错），每级打上溯源徽标；配备高德 8s 超时与单路线 40 次配额熔断。
  • 主动核验与区域闸门防御：对模型产出坐标直查高德核验，偏差 ≤1.5km 自动校正；设置地理省市闸门（≤200km 锚点）拦截同名误匹配，根治异地漂移问题。
  • 确定性代码消除幻觉：闭馆日冲突检查刻意设计为零 LLM、零网络纯算术模块；出发日期推断显式标记“推断可改”，无法判定如实提示。
  • 实体级 RAG 长期记忆库：按 place_card 实体级切分攻略，通过本地 fastembed (bge-small-zh-v1.5) 生成 512 维向量，结合 SQLite 向量索引精准检索注入（严格限制 ≤6 条/≤1200 字防上下文污染）。
  • SSE 决策轨迹可观测工程：整轮流式推送 event: trace 决策轨迹，前端可视化呈现可折叠决策过程（模型选型、记忆命中、坐标来源等），将黑盒静默兜底升级为透明工程决策。
