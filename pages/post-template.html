如何用纯静态文件搭建这个博客

2026.01.16 · 编辑：ZLOONG · 约 5 分钟阅读

HTML CSS 教程

为个人主页添加一个博客是分享知识和记录成长的好方法。但很多时候，我们不需要一个像 WordPress 或 Ghost 那样复杂的动态博客系统。对于一个开发者来说，一个纯静态、用 HTML 和 CSS 构建的博客不仅维护简单、加载飞快，而且完全免费（托管在 GitHub Pages 上）。

第一步：规划文件结构

我们的目标是简洁。所以我们只需要几个核心文件：

  • index.html — 你的主页。
  • blog.html — 新的博客文章列表页。
  • post1.md, post2.md — 每一篇文章都是一个独立的 Markdown 文件。
  • workshop.css — 主样式表。
  • blog-workshop.css — 博客页面的专属样式。

第二步：创建文章列表页

这个页面的作用是作为博客的入口，展示所有文章。每个条目包含标题、日期、摘要和一个「阅读全文」的链接。

blog.html
<div class="post-entry">
    <h3>文章标题</h3>
    <p class="post-meta">发布日期</p>
    <p>文章摘要...</p>
    <a href="post-template.html?slug=post1">阅读全文</a>
</div>

纯静态的好处是：不需要数据库、不需要后端、不怕宕机、部署到任何地方都能跑。

— 工房笔记

第三步：动态加载 Markdown

通过 JavaScript 读取 URL 中的 slug 参数，然后 fetch 对应的 Markdown 文件，在前端解析并渲染。这样发布新文章只需要：

  1. 在 posts/ 目录新建 Markdown 文件
  2. 在 data/posts.json 添加一条记录
  3. 提交，完事

这就是全部了！通过这个简单的方法，你就有了一个可以随时扩展的静态博客。
