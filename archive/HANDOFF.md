## 0. 一句话

一个游戏开发者 / AI 应用开发者的个人主站首页改版。技术栈是纯静态 HTML + CSS + 原生 JS，零依赖、无构建、部署 GitHub Pages。这次**只改个人站的「屏」部分**，另一个站（Hanako 箱庭）保持纸感不动。

## 1. 你先要知道的三件事

**① 原来的方向是错的。** 旧站叫「ZLOONG 工房」，整套视觉是暖纸 + 便签 + 印章 + 报纸拟人（"编辑：ZLOONG · 排印：Hanako"）。用户明确说：**"工房这个概念……不是我的真实意志"**，它只是从隔壁站（Hanako 箱庭）顺延过来的。所以这次是**换身份层**，不是换皮。

**② 触发点是对比。** 用户刷到 `huxx.me/zh/`，觉得"一致性非常好"。但拆开看，huxx 的一致性不是配色，是三件事：
- 句法恒定：一个 Part 的头永远是「编号 + 竖线 + 名称 + 右侧项目数」，一件作品永远是「图 + 标题 + 一句话 + 标签」；
- 主张恒定：他全站都在说"我是做游戏的"，连等级条、W/S 键、可玩小游戏都在替他说；
- 取舍恒定：加任何东西都能回答"这更像游戏了吗"。

用户要的是**这种**一致性，不是他的蓝色和圆角。

**③ 用户真正的审美渴望是"立体"。** 他在十几轮尝试里反复否决了：键帽、新拟物、玻璃方块、扫描线。问到根上，他说："**我一直很想营造的就是图形学的东西，或者说我就是想塞点立体的、3D（2D 伪造的 3D）的东西。**"他是计算机在读，刚开始学图形学。

这一条决定了母题的方向。

## 4. 自定的三条判据（用来筛任何新元素）

用来否定"再加点什么吧"这类提议：

1. **它得回答一个问题**，不是营造一种气氛。检验：问「它在说什么？」，若答案是"科技感 / 活跃 / 高级"，不合格。
2. **换一个人用就不成立**。检验：把页面上的名字换成另一个开发者，它还成立吗？成立 → 装饰。
3. **它必须能被停下来**。检验：读者停在那儿 30 秒，它还在动吗？还在动 → 迟早被讨厌，而且 reduced-motion 一开就消失。

> 这三条否掉了用户自己提的"背景落方块"（三条全不过），但留下了里面的「落定」这个语义。

## 7. 我自己不满意的地方（请重点看这里）

**① 「状态靠位置」可能是伪需求。** 水位图里，立方体的高低表示状态；但下面每件作品**已经写了状态标签**（已上线 / 在制 / 已归档）。既然信息重复，那水位图到底是"图表"还是"装饰"？按我自己第 1 条判据（它回答什么问题），它答的是一份已经答过的问题。这是母题最大的风险。

**② 26px 的立方体读不出立体。** 我们试过给每个作品行放一枚 26px 的立方体，放大看是一块灰方块——三个面挤在 26 个像素里。所以改成了水位图（46px）。**"立体"有最小尺寸门槛**，这次差点翻车。

**③ 冷白让页面更接近"现代 SaaS 落地页"的默认脸。** 玄黑至少还有点个性，冷白 + 无衬线 + 淡灰线 + 圆角为零，这个组合非常容易读成"模板"。用户之前已经说过一次"感觉很 normal"。

**④ 首页只有两屏**（名字 + 现在那一件）。拆出作品页之后它变短了。这是设计意图（首页只做一件事），但也可能显得像一张名片，空。

**⑤ 「关于」内容偏薄**：三句话 + 一张 7 行的表 + 一枚立方体。独立成页可能是过度拆分。

**⑥ 和一个还在跑的现实断层**：全站唯一的"活"元素被否掉了（下落方块），页面完全静态。对一个"做游戏的人"，这是不是太安静了？

**⑦ 子页材质断层**：首页/作品/关于是屏，而档案架 / 履历 / 画廊 / 洛天依仍是纸（暖纸 + 便签）。同一个域名下两套材质并存，这次是刻意不动的，但用户会看到。

**⑧ 素材质量不齐**：`像素火影` 那张图其实是 B 站视频封面（上面压着「秽土柱间 全技能介绍」六个大字），已降级成"无图、一行字"。`TriHorny4Link` 在旧数据里和像素火影共用同一个 b23 短链，说明至少一条是错的，现在两条都没放，显示「演示待补」。

## 10. 附：几条不能改的规则原文

**面板装内容，按键做操作**（唯一从旧方案原封继承的一条）

| 状态 | 判据 | 用在哪 |
|---|---|---|
| 平贴 | 我只是读它 | 正文、刻度、章节头 |
| 凹陷 | 内容被嵌进屏幕 | 图框、输入、代码 |
| 凸起 | 点它会做事 | 跳转键、复制键 |
| 按下 | 已触发 | 所有凸起，下沉 2px、120ms |

**色的四个岗位**：玄黑/冷白 = 底与字；青绿 = 状态（**只给「现在能上手」的东西**，在制/归档用灰）；朱砂 = 标记（章节编号，每屏最多一处）。

**母题规则**：等距（平行投影）立方体，三个面一个光向、三个明度；**位置即状态**——坐在线上 = 已上线，悬空 = 在制，沉到线下只露顶 = 已归档；**不画影子**（深色底上的影子等于没有，画了就是假的）。立体全站只有这一种物件，图板、按键、面板一概不加厚度。
