## 3. 唯一的视觉主张（全文最重要的一条）

**内容用「面板」，操作用「按键」。两者永不同形。**

| | 面板 | 按键 |
|---|---|---|
| 装什么 | 作品图、一段话、状态清单、页脚 | 导航、在投、邮箱、任何会被点的东西 |
| 形状 | 矩形，图片保持原比例、**绝不裁成圆形** | 圆角很小（3px）或正圆（50%） |
| 立体 | **平贴**，只有色阶和细线，没有凸起 | **凸起**，按下去有行程 |
| 数量 | 可以很多 | 一屏不超过 8 个 |

这条规则是整套设计的骨架。违反它，页面就会"说不上来地违和"——因为观众潜意识里知道图和键不是一类东西。

### 参考：huxx.me 的结构，不是皮

`https://huxx.me/zh/` 值得学的是**结构**，不是配色和画风：

- **章节编号**：`01 游戏设计 / 02 游戏开发`，巨大的数字压着小标题，一条通栏线收口。页面因此有"章"。
- **每件作品 = 大图 + 一块说明板**：图占 60%，旁边只写三样——时间、标题、一句话，底下三个标签。
- **左右交替**：图-板、板-图，节奏是摆动的，不是往下码一列卡片。
- **色只做标记**：颜色只出现在章节号、左条、关键词上，从不铺满。
- **一个主张贯穿全站**：他的每一页都在说"我是游戏开发者"。**别抄他的蓝色和卡片，抄他的纪律。**

## 4. 材质（已定稿，不要再改）

暖纸 + 单向光边。**不要描边，不要玻璃，不要塑料高光。**

```css
--case:  #E0D5BD;   /* 最外壳 */
--plate: #E9DFC9;   /* 底板，内容坐在上面 */
--wall:  #E0D5BC;   /* 键帽侧壁，比面暗一档 */
/* 键面 / 面板：对角，只有 3% 明度差 */
--face: linear-gradient(135deg, #FCF9F1 0%, #F4ECDB 100%);

/* 凸起：光在左上、暗在右下 */
--raise: -6px -6px 16px rgba(255,253,247,.95),
          9px 10px 22px rgba(112,92,64,.20);
/* "边"不是 border，是单侧光边 */
--edge:  inset 1px 1px 0 rgba(255,255,255,.90),
         inset -2px -2px 3px rgba(96,77,52,.16);
/* 按下：只塌行程与影，不位移、不变色 */
--press: -3px -3px 8px rgba(255,253,247,.85),
          4px 5px 10px rgba(112,92,64,.16),
          inset 1px 1px 0 rgba(255,255,255,.60);
```

三条纪律：

1. **全页不许出现 `border`。** 边界只能由「色阶差 + 单侧光边 + 影子」构成。
2. **圆角 3px 是"锐"的来源**，不是描边。正圆（50%）只给按键。
3. **按下是唯一允许的动效**：行程 3–4px，时长 120–160ms，`cubic-bezier(.2,.7,.3,1)`。

## 5. 字号与排印

- 正文 **16–17px**、行高 1.85、行宽 ≤ 46em；中文正文用衬线（`Songti SC / SimSun / Georgia`）。
- 界面文字（导航、按钮标签）用无衬线，**14px 起**。
- 等宽（`Cascadia Code / Consolas`）只用于：日期、编号、数字、标签。**最小 12px，绝不用于段落。**
- 大标题可以用 40–72px 的无衬线粗体；一屏只允许**一个**这样的巨头。

## 7. 交互

- 点作品 → 那一行说明换成该作品的一句话，**不跳页**。同一时间只有一件是"选中"。
- 点导航 → 真的会跳转（档案架 / 履历 / 画廊 / 洛天依）。
- 键盘可聚焦（`:focus-visible` 2px 朱砂描边），`prefers-reduced-motion` 下取消所有过渡。
- 不做滚动动画、不做视差、不做打字机。

## 8. 明确不要

- ❌ 描边（`border`）、玻璃拟态、模糊、发光、彩色渐变。
- ❌ 把作品图裁成圆形、做成卡片墙、做成"键帽"。
- ❌ 六个长得一样的并列按钮（那是没有主张的填空）。
- ❌ 把"键盘"当纹样贴在每一处（侧壁、凹槽、刻度）——**机械感来自按下去那一下，不来自表面装饰**。
- ❌ emoji 当图标；`Inter`/`Roboto` 当标题字体。
- ❌ 任何 `<br>` 硬断行做视觉排版。

## 9. 技术约束

- 单页纯静态；可以新增 `css/home.css`，但**必须复用 `css/tokens.css` 的纸墨变量**（改值只改 tokens）。
- 不引 CDN 字体、图标库、JS 框架；不用 `localStorage` 存设计状态。
- 响应式：1440 / 1024 / 390 / 320 四档都要成立，无横向溢出。
- **不要 `git commit`**，不要改 `LICENSE`、备案号、`legacy/`。
- 交付：`preview.html`（首页新稿，不动 `index.html`）+ 四档截图。

## 10. 验收

- [ ] 一条主张能被外人一句话说出来（"面板装内容，按键做操作"）。
- [ ] 全页零 `border`；轮廓全部由色阶与光边构成。
- [ ] 作品图是矩形、完整、未被裁切；按键是圆的或 3px 圆角。
- [ ] 按下有 3–4px 行程，松手回位。
- [ ] 一屏内巨头不超过 1 个，可见文本块 ≤ 25 个。
- [ ] 最小字号 ≥ 12px，正文 ≥ 16px。
