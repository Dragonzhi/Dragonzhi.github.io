# 博客系统改造：从手动更新到动态加载

在之前，我的博客系统非常原始。每当我想发布一篇文章，我都需要手动完成以下步骤：

1.  复制一个 HTML 文件作为模板。
2.  用文章内容填充这个 HTML 文件。
3.  上传到 `pages` 目录。
4.  最麻烦的是，我还需要手动去修改 `blog.html` 文件，在文章列表中加入指向新文章的链接。

这个过程不仅繁琐，而且极易出错。于是，我进行了一次小小的升级。

## 新方案：JS + JSON + Markdown

新的方案核心思想是“数据与视图分离”。我不再编写独立的文章 HTML 页面，而是让 JavaScript 去动态生成它们。

### 1. 内容存储

所有文章现在都以简洁的 **Markdown (`.md`)** 格式存储在新的 `/posts` 文件夹中。这让我可以更专注于写作本身，而不是 HTML 标签。

### 2. 文章索引

我创建了一个 `/data/posts.json` 文件，它像一本书的目录，记录了所有文章的元信息（标题、日期、摘要、对应的文件名等）。

```json
[
    {
        "slug": "post2",
        "title": "博客系统改造...",
        "date": "2026-01-24",
        "summary": "...",
        "file": "posts/post2.md"
    },
    {
        "slug": "post1",
        "..."
    }
]
```

### 3. 动态渲染

-   **列表页 (`blog.html`)**: 页面加载时，一段 JavaScript 会自动获取 `posts.json` 的内容，并动态地将所有文章列表渲染出来。
-   **文章页 (`post-template.html`)**: 我创建了一个通用的文章模板。当你点击一篇文章时，这个模板会根据 URL 参数（如 `?slug=post2`）知道要显示哪篇文章。然后，它会加载对应的 Markdown 文件，并使用 [marked.js](https://marked.js.org/) 库将其瞬间转换成 HTML，呈现在你眼前。

通过这次改造，发布新文章的流程简化为：**写一个 Markdown 文件，然后在 JSON 文件里加一条记录**。一切都变得自动化了，非常高效！
