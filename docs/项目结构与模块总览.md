## 一、项目是什么

ZLOONG 工房个人主站：纯静态 HTML + CSS + 原生 JavaScript，**无框架、无构建工具、无 npm**。部署在腾讯云（主站 `dragonzhi.xyz`，nginx 静态 + GitHub Actions SSH 自动 pull），GitHub Pages（`dragonzhi.github.io`）作静态镜像。与「隔壁箱庭」（`dragonzhi.xyz/hanako/`，另一个仓库的每日日报）同院互链。

唯一的第三方依赖例外：工房印章按需加载的 **three.js r159 UMD**（CDN），窄屏不加载、无 WebGL 退化为 2D 印章。

## 三、功能模块

### 1. 首页台面（`index.html` + `js/workshop.js`）

工房 Workshop 版面：门牌报眉 → 报头墙 → 今日一言 → 台面（可拖拽纸卡 bento）→ 本区导览牌 → 报尾（含备案号与 SIGNAL 入口）。

- **数据流**：about / now / links / motto / 今日一言全部 fetch `files/` 下源文件渲染，打字机读 `data/content.js` 的 `phrases`，台面尺寸读 `data/desk-config.js`。每个 fetch 独立容错，失败不打扰、绝不白屏；HTML 里的静态内容只是无 JS 兜底。
- **台面拖拽**：桌面端（≥1081px 且 pointer:fine）每张贴贴可拖，位置存 `localStorage` 键 `zloong-desk-v2`；「还原台面」按钮清档复位；拖动提示条可被永久关闭（键 `zloong-desk-hint-dismissed`）。台面随内容自动撑大（`fitDesk`），档案架无存档时默认落在档案册下方 24px。
- **自发现档案架**：`data/files-manifest.json` 里 `auto: true` 的条目，逐个 fetch `files/` 对应文件渲染成卡；外观由条目的 `style` 字段**手动指定**（`links`/`list`/`quote`/`doc` 四型，不写或非法值默认 `doc`），不做内容自动判型、不做随机。
- **今日一言**：`files/daily.txt`，每条两行（正文 + 落款），按 UTC 天序号取模轮换，同一天全世界同一句。
- **SIGNAL 彩蛋**（全站唯一允许发光处）：页脚按钮 / 任意页面键入 `66ccff` / `ESC` 关闭，弹出收音机弹层。

### 2. 工房印章（`js/seal.js` + `css/seal.css`）

3D 单物件方向（case-3）落地：视口右下角一枚 168×168 three.js 印章，拖到任意纸卡上按下即盖朱砂印（田字格「验收完成」+ SHIPPED · NO.xx），盖完自动归位；双击回位；键盘 Enter/空格 盖在最近的纸卡上。

- 印子存 `localStorage` 键 `zloong-seal-v1`：只记卡名、卡内 px 坐标、角度、透明度、序号与随机种子（不存图片），最多 48 枚，超出丢最早。
- 清除键 `#seal-clear` 贴在印章上方，两段式确认（先「上膛」再「抹掉」），有印子才出现。
- 边界（写死在 `js/seal.js` 头注）：窄屏 ≤1080px 整块不出现且**不下载 three.js**、已存印子也不渲染；无 WebGL 或加载失败退化为 2D 印章，功能不丢；静止时一个 rAF 都不跑（按需渲染）。
- three.js r159 UMD 从 jsdelivr CDN 按需加载，8 秒超时兜底。

### 3. 子页面（`pages/`，工房风格）

| 页面 | 定位 | 数据 |
|---|---|---|
| `pages/gallery.html` | 画廊版 · 洛天依同人画廊 | fetch `images/gallery-images.json`（脚本生成），灯箱翻页为页内脚本 |
| `pages/portfolio.html` | 档案架 · 作品集存档 | fetch `data/portfolio.json` |
| `pages/resume.html` | 技术履历 · 求职页 | 纯静态内嵌；三轨标签（AI 应用开发 / 游戏与系统工程 / 完整全景）+ A4 打印导出 |

- `resume/index.html` 只是跳转页，真正的履历页是 `pages/resume.html`（改文案直接改它）。
- 首页入口：hero 台面的 resume.md 档案卡 + 导览牌伍；导览牌另指画廊版（壹）、档案架（贰）、IterTrip（叁，外部部署 `/itertrip/`，不在本仓库）、隔壁箱庭（肆）。

### 4. 洛天依歌单页（`luotianyi/`）

「精修编年目录」：左侧常驻年份索引轨 + 右侧编年曲目长流，天依碧印点缀；`app.js` 只做即时搜索 / 标签过滤 / 年份高亮，无 JS 也能完整阅读。

- **数据唯一来源是外部仓库 `Dragonzhi/luotianyi-song-list`（master 分支）**，改数据去那个仓库。
- `python scripts/generate_luotianyi.py` 从该仓库拉取并生成 `luotianyi/index.html`（内容全内嵌，无 fetch）；`--offline` 用本地快照。
- `luotianyi/洛天依歌单.md` 是脚本写入的同步快照（兼离线回退，可线上直链引用），**勿手改**。
- 首页入口：`files/luotianyi.md` 走自发现机制成的卡。

### 5. 画廊索引

`images/画廊/` 放图 → `python scripts/generate_gallery_json.py` 重新生成 `images/gallery-images.json`（勿手改）。画廊版子页 fetch 该索引渲染。

### 6. 退役模块（`legacy/`）

- **博客**：2026-09-30 整体迁入 `legacy/`（`blog.html` + `post-template.html` + `posts/`），主导航与子页导览移除入口。根目录 `posts/` 已删除；`data/posts.json` 仅剩 `legacy/blog.html` 在 fetch，属于存档配套。
- **旧主题首页 / 作品集 demo**：`legacy/index.html`、`legacy/portfolio.html` 及其配套（根目录下的 `css/style.css`、`css/transition.css`、`css/site.css`、`css/portfolio-demo.css`、`js/script.js`、`js/transition.js`、`js/site.js`、`js/portfolio-demo.js`）。存档保留，不参与线上。

## 五、构建与部署

- **无构建**：改完即上线，本地验证 `python -m http.server 8000`（勿用 `file://` 判断 fetch）。
- **部署管线**：push `main` → GitHub Actions（`.github/workflows/deploy.yml`）SSH 到腾讯云执行 `ci-pull.sh`（`git pull` 到 `/var/www/dragonzhi`）→ nginx 静态即生效，无需 reload。
- **GitHub Pages 镜像**：`dragonzhi.github.io`（Fastly CDN，推送后缓存最长约 10 分钟）。
- **箱庭**：`dragonzhi.xyz/hanako/` 由另一个仓库（hanako-diorama）负责，systemd 端口 8421，与本仓库无耦合。
