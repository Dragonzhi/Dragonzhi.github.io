
## 1. 档案架卡片（files/ 目录自动成卡）

### 1.1 新增一张卡片

1. 在 `files/` 里新建一个 `.md` 或 `.txt` 文件，例如 `工具箱.md`；
2. 跑索引生成脚本：

```bash
python scripts/generate_manifest.py
```

3. 打开 `data/files-manifest.json`，给新条目加上 `style` 字段指定外观（见 1.2）；
4. 刷新页面，首页档案架自动多一张卡。

约定：

- 文件名（含扩展名）直接成为卡片标题；
- `about` / `now` / `links` / `motto` 是内置卡片名，同名文件不会重复生成卡；
- `daily.txt` 在排除名单里，永远不会上档案架；
- 重新跑生成脚本**会保留**你手改过的 `style` 字段（非法值被丢弃，卡片落到默认 doc）。

### 1.2 配置卡片外观（style 字段）——全手动

卡片样式**不做自动判型、不做随机**，在 `data/files-manifest.json` 对应条目里手写一个值：

| style 取值 | 渲染成 | 适合的内容写法 |
|---|---|---|
| `"links"` | 链接列表卡 | 每行 `- [文字](链接) 尾注`；尾注自动变灰补 ↗；邮箱行 `- 邮箱 {copy}` 带复制按钮；外链自动新窗口 |
| `"list"` | 圆点列表卡 | 每行 `- 文字` |
| `"quote"` | 黄便签引用卡 | 首段（`>` 引用块）是引文，空行后的段是落款 |
| `"doc"` | 段落文档卡（**默认**） | 任意段落、混合内容；不写 `style` 或写了非法值都是它 |

示例：

```json
[
  { "filename": "工具箱.md", "title": "工具箱.md", "auto": true, "style": "list" },
  { "filename": "随想.md", "title": "随想.md", "auto": true, "style": "quote" }
]
```

注意：内容套了不适配的渲染器也有优雅降级（比如 quote 型遇到普通段落会按便签正文显示），不会坏版，但建议按上表「适合的写法」准备内容。

### 1.3 卡片内支持的迷你 Markdown

所有档案卡正文走内置迷你解析器（无第三方依赖），支持：

- `` `code` `` → 等宽标签
- `**粗体**`
- `[[在制]]` → 朱砂状态徽章
- `[文字](链接)` → 链接（只放行 `http(s):` / `mailto:` / 站内相对路径，拒绝 `javascript:` 等危险协议）

**其余一律按纯文本显示，不解析原始 HTML**（规避 XSS）。

## 3. 台面（桌面工作区）

### 3.1 台面尺寸范围

只改 `data/desk-config.js` 这一个文件，刷新即生效：

| 字段 | 当前值 | 含义 |
|---|---|---|
| `minHeight` | 1280 | 台面最小高度(px)，内容更多时会自动超过它 |
| `padBottom` | 80 | 撑高时在最高卡片底部再留的余量 |
| `minWidth` | **0** | 台面目标宽度(px)，`0` = 自动随版心宽 |
| `padRight` | 24 | 撑宽时在最右卡片右沿再留的余量 |
| `padding` | 24 | 卡片到桌沿的边界留白(px) |

⚠ **`minWidth` 保持 0，不要贸然调大**：置大于版心宽会触发 `--desk-shift` 群组偏移，把右锚卡片（about / now / links / motto）整体向左推，实测会盖住 hero 卡文案（2026-09-20 复现后改回 0）。确实需要更大拖动范围，先修 `js/workshop.js` 的 desk-shift 逻辑。

### 3.2 卡片拖拽与存档

- 桌面端（视口 ≥1081px 且鼠标精细指针）可以直接按住卡片拖拽摆放，拖动提示条可点掉（记住选择）；
- 拖完的位置自动存进浏览器 `localStorage`（键 `zloong-desk-v2`），刷新不丢；
- 台面上的「还原台面」按钮一键恢复默认布局（同时清掉存档）；
- 档案架的默认位置是动态计算的：始终排在档案册（projects 卡）下方 24px 处，档案册内容变长也不怕被压住。

## 4. 工房印章（3D 单物件）

首页视口右下角有一枚印章（`js/seal.js` + `css/seal.css`）：拖到任意纸卡上按下即盖章（田字格「验收完成」+ SHIPPED · NO.xx），盖完自动归位；双击印章回位；键盘 Tab 聚焦后按 Enter / 空格 盖在最近的纸卡上。

- 印子自动存浏览器 `localStorage`（键 `zloong-seal-v1`，只记坐标与随机种子，最多 48 枚，超出丢最早），刷新不丢；
- 印章上方挂着「抹掉印章」按钮：**两段确认**（先点一次上膛，再点一次才真抹），有印子才出现；
- 窄屏（≤1080px）印章整块不出现、不加载 three.js，已存印子也不渲染；无 WebGL 或加载失败自动退化为 2D 印章，功能不丢；
- **全站唯一第三方依赖**就是这里按需加载的 three.js r159 UMD（jsdelivr CDN），其余页面保持零依赖；
- 想撤掉这个功能：删 `js/seal.js` + `css/seal.css` + `index.html` 里的 `#seal-rig` / `#seal-clear` 区块即可，互不影响其他模块。

## 5. 子页面（pages/）

三个工房风格子页，均为静态 HTML + 少量 fetch，**改内容直接改对应 HTML 文件**：

| 页面 | 内容 | 数据 |
|---|---|---|
| `pages/gallery.html` | 画廊版 · 洛天依同人画廊 | fetch `images/gallery-images.json`（见第 7 节） |
| `pages/portfolio.html` | 档案架 · 作品集存档 | fetch `data/portfolio.json` |
| `pages/resume.html` | 技术履历 · 求职页 | 全部内嵌在 HTML 里 |

- 技术履历页是招聘方入口，信息架构为「筛选者扫读」设计：顶部求职意向 → 技能矩阵（分类技能卡）→ 关键项目 → 软著与荣誉 → 教育。页顶三个标签轨（AI 应用开发 / 游戏与系统工程 / 完整全景）切换视图，右上角「导出 PDF / 打印」走浏览器打印（A4 样式已适配）。**简历 PDF 一律不托管到站上**，只保留邮件索取通道，不要往仓库里放。
- `resume/index.html` 只是跳转页（自动跳到 `pages/resume.html`），改简历文案不要改它。
- 首页入口：台面 resume.md 档案卡 + 导览牌伍。

## 6. 洛天依歌单页（luotianyi/）

独立页面 `/luotianyi/`：左侧常驻年份索引轨 + 右侧编年曲目长流，支持即时搜索 / 标签过滤 / 年份高亮；无 JS 也能完整阅读。

- **数据唯一来源是外部仓库 `Dragonzhi/luotianyi-song-list`（master 分支）**：改歌单去那个仓库改，本仓库只消费；
- 改完数据后在本仓库跑：

```bash
python scripts/generate_luotianyi.py            # 拉取歌单仓库最新数据并重生成页面
python scripts/generate_luotianyi.py --offline  # 断网时用上次同步的本地快照
```

- `luotianyi/洛天依歌单.md` 是脚本写入的同步快照（兼离线回退，线上可直接访问供引用），**不要手改**；
- `luotianyi/style.css` 与 `luotianyi/app.js` 是静态伴生文件，不随脚本生成，可正常手改；
- 首页入口：`files/luotianyi.md` 走自发现机制成的卡（勿删，删了首页就没有入口）。

- 推送到 `main` 分支 → GitHub Actions（`.github/workflows/deploy.yml`）自动 SSH 到腾讯云执行 `ci-pull.sh`（`git pull` 到 `/var/www/dragonzhi`），nginx 静态文件即生效，无需 reload；

## 9. 红线（不要动的东西）

- `<title>` 固定为「ZLOONG 工房 · Hanako箱庭」（工信部备案核查比对首页 title）；
- 页脚备案号「闽ICP备20260330551号-1」不得删改；
- 不删 `legacy/` 存档目录，不改 `LICENSE`；
- 不引入打包器、框架或 npm 依赖；**唯一例外**是工房印章 `js/seal.js` 按需加载的 three.js r159 UMD（窄屏不加载、失败退化 2D），除此之外新增依赖前必须先征得同意；
- 发光效果只允许出现在 SIGNAL 彩蛋一处，不新增；
- 所有 fetch 必须容忍失败，绝不白屏；保持响应式与无障碍（窄屏单列退化，尊重 `prefers-reduced-motion`）。
