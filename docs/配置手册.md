# ZLOONG 工房 · 配置手册

本站是纯静态 HTML + CSS + 原生 JavaScript，无框架、无构建工具。所有日常配置只改数据文件，不改 HTML/CSS/JS。

## 快速索引

| 我想改什么 | 去哪改 | 怎么生效 |
|---|---|---|
| 新增一张档案架卡片 | `files/` 放新 `.md`/`.txt` → 跑生成脚本 | 刷新页面 |

| 改「今日一言」 | `files/daily.txt` | 刷新页面（按日期轮选） |

本地验证统一用：

```bash
python -m http.server 8000
```

然后浏览器开 `http://localhost:8000`。**不要用 `file://` 协议判断功能是否正常**（fetch 会跨域失败，造成误判）。改完看不到效果先按 `Ctrl+F5` 强制刷新。

## 1. 档案架卡片（files/ 目录自动成卡）

### 1.1 新增一张卡片

1. 在 `files/` 里新建一个 `.md` 或 `.txt` 文件，例如 `工具箱.md`；
2. 跑索引生成脚本：

```bash
python scripts/generate_manifest.py
```

3. 打开 `data/files-manifest.json`，给新条目加上 `style` 字段指定外观（见 1.2）；
4. 刷新页面，首页档案架（黄色便签下方区域）自动多一张卡。

约定：

- 文件名（含扩展名）直接成为卡片标题；
- `about` / `now` / `links` / `motto` 是内置卡片名，同名文件不会重复生成卡；
- `daily.txt` 在排除名单里，永远不会上档案架；
- 重新跑生成脚本**会保留**你手改过的 `style` 字段（非法值被丢弃，卡片落到默认 doc）。

### 1.2 配置卡片外观（style 字段）——全手动

卡片样式**不做自动判型、不做随机**，在 `data/files-manifest.json` 对应条目里手写一个值：

| style 取值 | 渲染成 | 适合的内容写法 |
|---|---|---|
| `"links"` | 链接列表卡 | 每行 `- [文字](链接) 尾注`；尾注自动变灰补 ↗；邮箱行 `- 邮箱 {copy}` 带复制按钮；外链自动新窗口 |
| `"list"` | 圆点列表卡 | 每行 `- 文字` |
| `"quote"` | 黄便签引用卡 | 首段（`>` 引用块）是引文，空行后的段是落款 |
| `"doc"` | 段落文档卡（**默认**） | 任意段落、混合内容；不写 `style` 或写了非法值都是它 |

示例：

```json
[
  { "filename": "工具箱.md", "title": "工具箱.md", "auto": true, "style": "list" },
  { "filename": "随想.md", "title": "随想.md", "auto": true, "style": "quote" }
]
```

注意：内容套了不适配的渲染器也有优雅降级（比如 quote 型遇到普通段落会按便签正文显示），不会坏版，但建议按上表「适合的写法」准备内容。

### 1.3 卡片内支持的迷你 Markdown

所有档案卡正文走内置迷你解析器（无第三方依赖），支持：

- `` `code` `` → 等宽标签
- `**粗体**`
- `[[在制]]` → 朱砂状态徽章
- `[文字](链接)` → 链接

**其余一律按纯文本显示，不解析原始 HTML**（规避 XSS）。

## 2. 内置卡片文案

| 卡片 | 源文件 | 说明 |
|---|---|---|
| 关于 | `files/about.md` | 自由段落 |
| 近况 | `files/now.md` | 想用圆点就每行 `- ` |
| 链接 | `files/links.md` | 每行 `- [文字](链接) 尾注` |
| 座右铭 | `files/motto.txt` | `>` 引用行，空行后是落款 |
| 今日一言 | `files/daily.txt` | 每条 2 行（正文 + 落款），条目间空行分隔；按日期轮选，次日自动换 |
| 打字机句子 | `data/content.js` | 改 `phrases` 数组 |

改这些文件即可，**不要直接改 index.html**（里面的静态内容只是无 JS 兜底，可以不同步）。

## 3. 台面（桌面工作区）

### 3.1 台面尺寸范围

只改 `data/desk-config.js` 这一个文件，刷新即生效：

| 字段 | 当前值 | 含义 |
|---|---|---|
| `minHeight` | 1280 | 台面最小高度(px)，内容更多时会自动超过它 |
| `padBottom` | 80 | 撑高时在最高卡片底部再留的余量 |
| `minWidth` | 1280 | 台面目标宽度(px)，`0` = 自动随版心宽 |
| `padRight` | 24 | 撑宽时在最右卡片右沿再留的余量 |
| `padding` | 24 | 卡片到桌沿的边界留白(px) |

### 3.2 卡片拖拽与存档

- 桌面端（视口 ≥1081px）可以直接按住卡片拖拽摆放；
- 拖完的位置自动存进浏览器 `localStorage`（键 `zloong-desk-v2`），刷新不丢；
- 台面上的「还原台面」按钮一键恢复默认布局（同时清掉存档）；
- 档案架的默认位置是动态计算的：始终排在档案册（projects 卡）下方 24px 处，档案册内容变长也不怕被压住。

## 4. 博客

1. 在 `posts/` 新建 Markdown 文章，如 `posts/post3.md`；
2. 在 `data/posts.json` 登记一条（新条目放数组最前面）：

```json
{
    "slug": "post3",
    "title": "文章标题",
    "date": "2026-09-07",
    "summary": "一两句摘要",
    "file": "posts/post3.md"
}
```

3. 推送后首页博客区自动出现新文章。

## 5. 画廊

1. 把图片放进 `images/画廊/`；
2. 跑索引生成脚本：

```bash
python scripts/generate_gallery_json.py
```

**不要手改** `images/gallery-images.json`（脚本生成物，手改会被覆盖）。

## 6. 部署

- 推送到 `main` 分支 → GitHub Actions 自动 SSH 部署到腾讯云；
- `dragonzhi.xyz` 是主站，GitHub Pages 是镜像；
- 页面经 Fastly CDN，推送后最多缓存 10 分钟，稍候即生效。
