## 一、通用图片规范

| 维度 | 建议规范 | 说明 |
| :--- | :--- | :--- |
| **画面比例** | **16 : 9**（最推荐）或 **16 : 10** | 媒体视窗顶部带有仿 macOS/浏览器控制台标题栏，16:9 比例在视窗内贴合最自然，不会裁切上下关键信息。 |
| **像素尺寸** | 宽度 **1200px ~ 1600px**<br>（推荐 `1200 × 675` 或 `1600 × 900`） | 页面中视窗宽度在 310px ~ 600px 之间，1200px+ 宽能确保在 2x/3x 视网膜高清屏（Retina）下边缘文字极度锐利。 |
| **单张体积** | **200 KB ~ 600 KB**（上限 ≤ 1 MB） | 纯静态网页秒开体验最佳。无损截屏体积偏大时，可用 [TinyPNG](https://tinypng.com/) 或 [Squoosh](https://squoosh.app/) 压缩。 |
| **图片格式** | **PNG** 或 **WebP** | 软件界面、代码与文字截图推荐 **PNG** 或无损 **WebP**（边缘不发糊）；照片或复杂渲染图亦可用优质 JPG。 |

## 三、HTML 替换步骤

图片放置完成后，有两种替换方式：

### 方式 A（推荐）：直接告知 AI
图片放入 `images/projects/` 后，在对话中直接发送「图片已放好，帮我替换 HTML」，AI 将自动把 `pages/resume.html` 中的占位块（`.placeholder-box`）批量替换为 `<img>` 标签。

### 方式 B：手动替换
在 `pages/resume.html` 对应项目的 `.media-window` 容器内，将：
```html
<div class="placeholder-box">
    ...
</div>
```
替换为：
```html
<img src="../images/projects/对应文件名.png" alt="项目描述" loading="lazy">
```
页面 CSS 已内置好悬停微缩放（`scale(1.02)`）与自适应比例适配规则，直接生效。
