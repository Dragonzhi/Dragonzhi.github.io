# RESULTS · 判据与记录

## 先写判据，后看东西

不要看完再定标准，否则一定会按「新奇度」打分，而新奇度不产生可用设计。

| # | 判据 | 看什么 |
|---|---|---|
| A | 回答了「现在跑到哪了」吗 | 作品状态是不是页面的一等结构，而不是角落里的一行日期 |
| B | 三秒说得清吗 | 这是谁的站、下一眼该去哪，不用读第三句 |
| C | 有没有真的装下六件作品 | 信息密度是否被留白吃掉；大图是否只是遮住了内容的贫乏 |
| D | 细节有没有手艺 | 对齐、行高、断行、图的处理、五档断点——而不是靠装饰堆出来的繁复 |
| E | 有没有一件「只有这个站会有」的东西 | 不是通用作品集模板能替换掉的那个点 |
| F | 能不能搬进现有壳 | 你只取概念即可重做；但概念本身要能被单独说出口 |

A–E 打 1–5，F 只写「能 / 不能 / 半」。

## 停手信号

- **六张卡结构同构** → 变体没生效，别选，直接重抽或换轴。
- **某张卡只在配色上不同** → 同上。
- **出现了「居中 hero + 渐显 + 三列卡」** → 模型没吃进 brief，这张作废。
- **全部落在 2–3 分** → 问题不在模型，在 brief 的题面（内容本身不够有张力）。
