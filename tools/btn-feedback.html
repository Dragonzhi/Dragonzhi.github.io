按钮反馈对比

同一枚 44px 铭牌，三种 hover 反馈：A 把面压暗一档；B 面压暗 + 一团白光跟着指针；C hover 什么都不变，只有按下的 1px。鼠标划过、按住，看哪种更像一块能被按的金属。三案的静止、按下（1px 行程 + 斜棱交换）完全相同。

A · 状态层

静止 hover 按下
试 2×

Material 3 / Apple HIG / Radix 这一路：hover 用 on-surface 覆盖（M3 是 8%），按下再深一档。状态清楚、和焦点同一套；不携带颜色语义。

B · 指针微光

静止 hover 按下
试 2×

Linear / Vercel 的 spotlight 卡、visionOS 的镜面 这一路：光跟着指针走，像手在表面上挪。要一点脚本更新坐标；白光要压在压暗过的面上才读得出，压暗为 0 时光斑等于不存在。

C · 纯行程

静止 hover 按下
试 2×

硬件面板 / Teenage Engineering 这一路：hover 不表态，世界里只有按下。最像实物，代价是鼠标用户移上去时不知道能不能点。

B HANAKO 箱庭 ↗ HANAKO 箱庭 ↗
C HANAKO 箱庭 ↗ HANAKO 箱庭 ↗

左为静止，右为 hover。三案都不再把字转青：青绿只回答「现在能不能玩」，不做悬停反馈。
