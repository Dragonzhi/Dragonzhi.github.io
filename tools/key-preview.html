按键拟物方案 · 四选一

四条路线都只走 CSS（无图、无第三方），色都在系统 token 里，光一律来自左上——和主名浮雕的受光棱一致。「悬停 / 按下」两行是静态演示（指针悬上时整组都同样成立），按下那格预先写成触发后的样子。

A · 键帽

现在 .btn 的亲儿子强化版：圆角软塑料面，一条顶高光 + 一条底缘硬线 + 柔接触影。最省、最贴现有仪表感，但拟物程度最浅。

B · 机械键程

两段台阶：按下先塌 3px 的硬弹片（硬阶消失在脚下），手感最「物理」。和「物理」基调最合拍，代价是阴影层最多、在哪都最醒目。

C · 内嵌刻井

键不是凸出来，是凹进去的：井底受下缘反光，字带刻字的「上暗下亮」双影，按下往井底再陷半像素。最静的一路——但和 §6.1「凸起 = 点它会做事」的职能义反着来，等于把键读成永不按下的坑。
